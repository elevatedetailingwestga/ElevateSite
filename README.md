# Elevate Detailing Website

Static website for GitHub Pages.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
3. In GitHub: Settings → Pages → Deploy from branch.
4. Select the branch and `/ (root)`.
5. Save.

## Add real photos
Replace the placeholder `<div class="placeholder ...">` blocks in `index.html` with `<img>` elements, or add a CSS background image.

## Edit business information
The phone, email, hours, service areas, pricing, and terms are all in `index.html`.

## Logo assets
